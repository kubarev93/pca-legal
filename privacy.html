Privacy Policy

Last updated: September 16, 2026

This Privacy Policy explains how Prime Clip Agent ("the Software") handles data. The Software is a personal automation tool operated by a single content creator to publish clips to that creator's own connected social accounts.

1. Who Operates the Software

The Software is self-hosted and run by its operator on the operator's own machine or server. There is no central service that collects data from end users. The operator is the data controller for any data the Software processes.

2. Data the Software Handles

The Software works with: (a) video files and campaign briefs the operator supplies or is authorized to use; (b) generated clips and their captions; and (c) API access tokens and refresh tokens for the social accounts the operator has connected. These items are stored locally in the operator's own environment and configuration files.

3. Platform Access Tokens

When the operator connects a social account (for example, via TikTok OAuth), the resulting access and refresh tokens are stored locally and used solely to publish content that the operator has explicitly approved to that same account. Tokens are not shared with any third party and are not transmitted to the authors of the Software.

4. Information from Connected Platforms

The Software requests only the minimum permissions needed to publish videos to the operator's own account. It does not collect, store, or process the personal data of other users of those platforms.

5. Data Sharing

The Software does not sell or share personal data. Content is transmitted only to the platform the operator chooses to publish to, using that platform's official API, and only after the operator approves the content.

6. Data Retention and Deletion

Because data is stored locally in the operator's own environment, the operator controls retention and deletion. Access tokens can be revoked at any time from the connected platform's settings, and local files can be deleted by the operator at will.

7. Security

The operator is responsible for securing the environment in which the Software runs, including protecting stored tokens and configuration files.

8. Children's Privacy

The Software is not directed to children and does not knowingly process data relating to children.

9. Changes

This Policy may be updated from time to time. Updates will be posted on this page with a revised "Last updated" date.

10. Contact

For questions about this Policy, contact the operator at the email address published on the operator's account or repository.
